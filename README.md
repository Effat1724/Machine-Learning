# Machine Learning

## Overview
This repository contains Machine Learning study materials, lecture notes, Python implementations, practical experiments, and projects for Computer Science and Engineering (CSE) students.

## Topics Covered
- Introduction to Machine Learning
- Supervised and Unsupervised Learning
- Linear Regression and Logistic Regression
- K-Nearest Neighbors (KNN)
- Naive Bayes
- Decision Trees and ID3 Algorithm
- Support Vector Machines (SVM)
- Artificial Neural Networks
- K-Means Clustering
- Model Evaluation Metrics
- Overfitting, Underfitting, and Cross-Validation
- Probability, MLE, and MAP
- Python and Scikit-learn Implementations

## Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Purpose
The purpose of this repository is to organize Machine Learning learning resources, algorithm implementations, solved problems, lab exercises, and academic projects in one place.
